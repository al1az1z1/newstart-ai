# data/processed/

Generated by `src/dataset/build_dataset.py` and `src/dataset/eda.py`.

Unlike `data/raw/` and `data/extracted_text/`, this folder **is** tracked in
git: `documents.csv` is the small, final handoff artifact for the BERT and
RAG teams (see Task 6 / `docs/dataset_summary.md`), not a large intermediate
by-product worth excluding.

- `documents.csv` -- the labeled dataset (`file_path, text, label, source_agency, document_type`)
- `eda_figures/` -- charts generated by `src/dataset/eda.py`
